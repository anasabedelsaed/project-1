# 🎮 Django Web Games Suite

مشروع تجميعة ألعاب تفاعلية خفيفة تم تطويرها باستخدام إطار العمل **Django** مع واجهات **HTML, CSS, JavaScript**، كجزء من متطلبات المعمل (Lab 1).

---

## 📌 نبذة عن المشروع

منصة ألعاب متكاملة تتيح للمستخدم الوصول إلى ثلاث ألعاب مختلفة من خلال صفحة رئيسية موحدة، وتتميز باستجابة فورية وسريعة بدون الحاجة لإعادة تحميل الصفحة أثناء اللعب.

---

## 🎯 الألعاب المضمنة

1. **🔢 لعبة تخمين الرقم (Number Guessing Game):**
   - يقوم النظام بتوليد رقم عشوائي من 1 إلى 100.
   - يدخل المستخدم التخمينات مع الحصول على تلميحات فورية (أكبر / أصغر) وحساب عدد المحاولات.

2. **✂️ لعبة حجر ورقة مقص (Rock Paper Scissors):**
   - مواجهة مباشرة ضد الكمبيوتر.
   - تحديد الفائز فورياً (فوز، خسارة، تعادل).

3. **❌⭕ لعبة إكس أوه (Tic-Tac-Toe):**
   - لعبة لشخصين على نفس الجهاز.
   - التحقق التلقائي من شبكة الفوز وإمكانية إعادة اللعب.

---

## 🛠️ التقنيات المستخدمة

- **Backend:** Python 3.x / Django Framework
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Version Control:** Git & GitHub
